# Rubilka / Рубилка

Browser strategy about seizing territory, in a single HTML file. English and Russian, switch in the menu.

Стратегия про захват территории в одном HTML-файле. Английский и русский, переключение в меню.

Maps: random, your own (built-in editor) and Europe 2013, where you pick any of 60 countries. Карты: случайная, своя (встроенный редактор) и Европа 2013, где можно играть за любую из 60 стран.

Europe 2013 map data: borders and cities from [Natural Earth](https://www.naturalearthdata.com/) (public domain), relief from [Mapzen Terrain Tiles](https://registry.opendata.aws/terrain-tiles/). Данные карты Европы: границы и города Natural Earth, рельеф Mapzen Terrain Tiles.
